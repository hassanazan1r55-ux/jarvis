ARIA Neural Interface

A Jarvis-inspired heads-up display concept, designed as an interactive browser experience using plain HTML, CSS and JavaScript.

Overview

ARIA explores the visual language of a futuristic command centre while keeping the experience self-contained in the browser. Its interface combines a central animated reactor, surrounding telemetry panels, radar and hologram visuals, and a command console.

What I built

  • A responsive HUD layout with telemetry and status panels.
  • Canvas-based radar, animated background particles, waveform and rotating hologram.
  • A text command interface with preset commands and optional speech input/output where browser support allows.
  • Audio synthesis controls, colour themes and a cinematic startup sequence.

Technology used

  • HTML
  • CSS animations
  • Vanilla JavaScript
  • Canvas 2D
  • Web Audio API
  • Web Speech APIs

Browser permissions and API availability vary by device. Telemetry shown in the HUD is illustrative interface data, not a system diagnostic tool.
